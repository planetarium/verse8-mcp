---
name: incanto-game-feel
description: |
  Measure what your controls actually feel like — `bunx incanto-feel` reports top speed,
  ramp and stop times, turnaround, jump apex and airtime, and the coyote / jump-buffer
  windows MEASURED by probing rather than read from the schema. Use when tuning a
  character, or when a game feels off and you cannot see why.
---

## Instructions

1. Ensure the package is installed. If not, run: `bun add incanto three`
2. Read the documentation file at `node_modules/incanto/skills/incanto-game-feel.md` and
   follow its instructions — it always matches the INSTALLED engine version.
