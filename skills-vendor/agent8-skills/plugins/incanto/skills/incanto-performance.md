  Graphics settings the engine provides so your game does not have to invent them —
  quality tier (shadows/bloom/post), frame cap, resolution scale, and the one lever
  (antialiasing) that can only change at boot. Use when supporting low-end devices or
  building a settings menu.

## Instructions

1. Ensure the package is installed. If not, run: `bun add incanto three`
2. Read the documentation file at `node_modules/incanto/skills/incanto-performance.md` and
   follow its instructions — it always matches the INSTALLED engine version.
