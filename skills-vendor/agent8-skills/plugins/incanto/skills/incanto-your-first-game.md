## Instructions

1. Ensure the package is installed. If not, run: `bun add incanto three`
2. Read the documentation file at `node_modules/incanto/skills/incanto-your-first-game.md` and
   follow its instructions — it always matches the INSTALLED engine version.
3. **Start at its §2.** §1 scaffolds a fresh project with `incanto new`, which never happens
   here: a project on this platform arrives from a start template, already scaffolded and
   already installed. Everything from §2 on is what you came for — what you edit, the shape
   of a game that can be won and lost, the traps in §4, and the headless checks in §5.
